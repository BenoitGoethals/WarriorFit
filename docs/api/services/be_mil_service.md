# BE Mil Service

External HR system integration via HTTP. Retrieves military personnel data from the Defence HRM API using API key authentication.

## Classes

- **`ServiceMenSchema`** — Pydantic model for ServiceMen validation and serialization
- **`BEMILService`** — HTTP client for the external HR API
