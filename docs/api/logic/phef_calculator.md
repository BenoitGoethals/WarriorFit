# PHEF Calculator

Utility class for calculating PHEF (Physical Fitness Evaluation) scores. Computes side-bridge and 2400m running results based on age, gender, and performance data tables.

## Scoring

- **Side-bridge**: Left and right hold times scored by age/gender table (max 20 pts each side, lowest counts)
- **2400m run**: Time-based scoring by age/gender table (max 20 pts)
- **Total**: 40 points maximum
