# MFFT Eval Calculator

MFFT Eval scoring calculator. Scores the 8-event evaluation (6-min EMOM + 4800 m run + 200 m combat swim) against age/gender-neutral COMBAT thresholds or age-bracketed ENABLER thresholds, returning per-event tiers and an overall pass/fail.
