# Asset Inventory

Significant components, their purpose, and responsible parties. Update when adding/removing major components.

**Default owner:** @BenoitGoethals (see `CODEOWNERS`)

## Application

| Component                       | Path                              | Purpose                                                                 |
|---------------------------------|-----------------------------------|-------------------------------------------------------------------------|
| App entry point                 | `warriorfit/app.py`               | Boots DI container, registers pages, manages broker lifecycle           |
| DI container                    | `warriorfit/core/container.py`    | Wires repositories, services, controllers                               |
| Configuration                   | `warriorfit/config/`              | YAML-driven app config (dev/test/prod)                                  |
| Security                        | `warriorfit/security/`            | Argon2id hashing, RBAC primitives                                       |
| ORM models                      | `warriorfit/data/model/`          | Polymorphic `FitnessTest` hierarchy and related entities                |
| Repositories                    | `warriorfit/data/`                | Async data access via `AsyncSession`                                    |
| Services                        | `warriorfit/services/`            | Business logic (scoring, consent, user, eligibility)                    |
| Message broker                  | `warriorfit/mom/broker.py`        | Async outbox worker for HR integration; retry + dead-letter             |
| Shiny pages (UI)                | `warriorfit/ui/`                  | Reactive web UI, role-gated                                             |
| Static assets                   | `warriorfit/www/`                 | Served static files                                                     |
| Utilities                       | `warriorfit/utils/`               | Shared helpers                                                          |
